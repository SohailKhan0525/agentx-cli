# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.20.x  | :white_check_mark: |
| < 1.20  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within AgentX, please do NOT create a public GitHub issue.

Instead, please send an email to the repository maintainer or create a private security advisory via [GitHub Security Advisories](https://github.com/SohailKhan0525/agentx-cli/security/advisories/new).

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or proof-of-concept code.
- Any suggested mitigations.

We will review all security reports promptly and issue patches as necessary.
