> The AI agent that builds production-ready websites from your terminal.
> Describe your website. AgentX builds it, deploys it, ships it.
> Not a demo. Not an MVP. A real website, live on the internet.

## Install

npm install -g agentx-cli

## Use

agentx

Just describe what you want to build.

## What AgentX Does

1. You describe your website in plain English
2. AgentX picks the best tech stack
3. AgentX figures out what backend services you need
4. Guides you through API keys one at a time
5. Shows the full plan before writing any code
6. Builds every page with real production code
7. Fixes TypeScript errors and passes the build itself
8. Pushes to GitHub and deploys live
9. Your website is on the internet

## Supported Stacks

Next.js 14, React + Vite, Astro, Nuxt 3

## Supported Services

Clerk, Supabase, Firebase, Appwrite, MongoDB Atlas, PlanetScale,
Stripe, Lemon Squeezy, Resend, SendGrid, Postmark, Vercel,
Netlify, Railway, Fly.io, Cloudflare Pages, Render, AWS S3,
Cloudflare R2, Uploadthing, PostHog, Sentry, and more.

## Local Models

Supports Ollama, LM Studio, Jan, GPT4All, llama.cpp, LocalAI.
Detects your hardware and recommends the best model you can run.
Your conversations stay completely on your machine.

## Component Registry

Ships with premium UI components from ReactBits and 21st.dev.
Your website gets real, production-quality UI automatically.

## Requirements

- Node.js 18+
- An API key from OpenAI, Anthropic, or Google
  (or a local model via Ollama or similar)
