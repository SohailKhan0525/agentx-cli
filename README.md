## Install

### npm
```bash
npm install -g @agent-qofeno/agentx-cli
```

### Homebrew (macOS/Linux)
```bash
brew tap SohailKhan0525/agentx
brew install agentx
```

### GitHub Packages
```bash
npm install -g @SohailKhan0525/agentx-cli --registry https://npm.pkg.github.com
```

### JSR
```bash
npx jsr add @agent-qofeno/agentx-cli
```
