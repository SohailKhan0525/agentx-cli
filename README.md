> The AI agent that builds production-ready websites from your terminal.
> Describe your website. AgentX builds it, deploys it, ships it.
> Not a demo. Not an MVP. A real website, live on the internet.

## Install

```bash
npm install -g @agent-qofeno/agentx-cli
```

Works on Windows, macOS, and Linux.

## Use

```bash
agentx
```

Just describe what you want to build.

## What AgentX Does

1. You describe your website in plain English
2. AgentX picks the best tech stack automatically
3. AgentX figures out what backend services your site needs
4. Guides you through API keys one at a time with clear instructions
5. Shows the full plan before writing any code
6. Builds every page with real, production-quality code
7. Zero placeholders. Zero mock data. Zero unfinished functions.
8. Fixes TypeScript errors and passes the production build itself
9. Pushes to GitHub and deploys live
10. Your website is on the internet

## Local Models

AgentX detects your hardware (CPU, RAM, GPU, VRAM) and recommends
the best coding model your system can actually run — from fast
lightweight models to high-quality larger ones. Supports Ollama,
LM Studio, Jan, GPT4All, llama.cpp, and LocalAI. Downloads and
installs models automatically when possible.

Your conversations stay completely on your machine.

## Component Registry

AgentX ships with premium UI components from ReactBits and 21st.dev.
Your website gets beautiful, production-quality UI automatically.
Not generic boilerplate.

## Requirements

- Node.js 18 or higher
- An API key from one of the supported providers
