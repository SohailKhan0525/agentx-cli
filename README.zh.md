### 安装

```bash
# npm 全局安装
npm install -g @agent-qofeno/agentx-cli

# 或者使用 npx 直接运行
npx @agent-qofeno/agentx-cli
```

---

### 快速开始

```bash
agentx
```

直接使用自然语言描述你想要构建的网站，AgentX 将自动完成全栈架构、后端服务、数据库、UI 组件、测试修复和线上部署。
