# Supported Full-Stack Web Frameworks

AgentX is engineered specifically for modern full-stack web architectures.

---

## ⚡ Framework Directory

### 1. Next.js 14 / 15 (App Router)
- **Best For**: Enterprise full-stack SaaS, e-commerce, web applications, dashboards
- **Architecture**:
  - React Server Components (RSC)
  - Server Actions for form handling and backend mutation
  - Route Handlers (`app/api/`)
  - Integration with Prisma / Drizzle ORM, Supabase, Neon, NextAuth / Clerk, Stripe

---

### 2. React + Vite
- **Best For**: Interactive single-page applications, client-side tools, games, canvas dashboards
- **Architecture**:
  - Lightning-fast HMR via Vite
  - React Router v6/v7
  - TanStack Query (React Query)
  - Zustand / Redux Toolkit state management

---

### 3. Astro
- **Best For**: Content-driven websites, marketing sites, blogs, portfolios, docs
- **Architecture**:
  - Zero-JS by default (Islands architecture)
  - Markdown / MDX collections
  - Hybrid SSR / static output

---

### 4. Nuxt 3 (Vue 3)
- **Best For**: Vue-based full-stack platforms
- **Architecture**:
  - Nitro backend engine
  - Universal Vue 3 SSR
  - Pinia state management

---

## 🎨 UI & Styling Engine

AgentX leverages best-in-class UI design principles powered by its internal design tokens:
- **TailwindCSS v3 & v4**: Modern responsive utility architecture
- **Lucide Icons**: Crisp vector iconography
- **Framer Motion**: Fluid entry transitions, hover animations, layout springs
- **Dark Mode**: Automatic system & user-toggled theme states
- **Accessible Components**: Radix UI, shadcn/ui patterns
