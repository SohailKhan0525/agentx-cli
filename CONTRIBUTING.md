# Contributing to AgentX

Thank you for your interest in contributing!

## Getting Started

1. Fork https://github.com/SohailKhan0525/agentx-cli
2. Clone your fork
3. Run bun install
4. Run bun run dev

## Adding Components to the Registry

Open components.txt and add:

NAME: Your Component Name
CODE:
paste full TSX code here

## Submitting Changes

1. Create a branch for your change
2. Make your changes
3. Run bun run build and confirm zero errors
4. Submit a pull request

## Issues

Report bugs at:
