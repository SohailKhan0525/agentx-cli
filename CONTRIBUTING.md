# Contributing to AgentX

Thank you for your interest in contributing to **AgentX**!

## Development Setup

### Prerequisites
- Node.js 18 or higher
- npm

### Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/SohailKhan0525/agentx-cli.git
   cd agentx-cli
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Build the CLI:
   ```bash
   npm run build
   ```

4. Test locally:
   ```bash
   node packages/agentx/dist/index.js --version
   ```

## Pull Request Guidelines

1. Fork the repo and create your branch from `dev`.
2. Follow our TypeScript style guidelines and ensure code builds with zero errors:
   ```bash
   npm run build
   ```
3. Submit your pull request at [github.com/SohailKhan0525/agentx-cli/pulls](https://github.com/SohailKhan0525/agentx-cli/pulls).
