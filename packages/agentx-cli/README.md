### Installation

```bash
# Global install
npm install -g @agent-qofeno/agentx-cli

# Instant execution
npx @agent-qofeno/agentx-cli
```

---

### Quickstart

```bash
agentx
```

1. Enter your website idea in plain English.
2. Select your AI provider (GitHub Copilot, OpenAI, Google Gemini, Anthropic, or Local Models).
3. Review the autonomous architecture blueprint.
4. Watch AgentX build full-stack code, databases, authentication, and deployment scripts with 0 placeholders.

---

### Features

- **Autonomous 9-Phase Generation**: Architecture, Backend, Database, Auth, UI/UX, Component Registry, Testing, Build Healing, and Deployment.
- **5 Supported AI Providers**: GitHub Copilot, OpenAI (`gpt-4o`), Google (`gemini-2.0-flash`), Anthropic (`claude-3-7-sonnet`), and Local Models (Ollama, LM Studio, Jan).
- **Component Registry**: Curated UI components from ReactBits and 21st.dev.
- **Built-in Self-Healing**: Automatically passes production build tests and resolves TypeScript errors before shipping.
