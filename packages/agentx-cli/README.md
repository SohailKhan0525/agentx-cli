## Quickstart

Run instantly with `npx`:

```bash
npx @agent-qofeno/agentx-cli
```

Or install globally:

```bash
npm install -g @agent-qofeno/agentx-cli
# or
bun install -g @agent-qofeno/agentx-cli

# Run anywhere
agentx
```

## Features

- **Full-Stack Website Generation** — Builds complete websites across Next.js 14+, React + Vite, Astro, and Nuxt 3.
- **Zero Placeholders** — No TODOs, no lorem ipsum, complete production code from minute one.
- **5 Supported Providers** — GitHub Copilot, OpenAI ChatGPT, Google Gemini, Anthropic Claude, and Local Models (Ollama, LM Studio, Jan, GPT4All, llama.cpp, LocalAI).
- **Offline & Private Mode** — Built-in hardware profiler and automatic model tier recommendations for local LLMs.
- **Beautiful Terminal UI** — Interactive TUI with command palette, model switching, and session management.
