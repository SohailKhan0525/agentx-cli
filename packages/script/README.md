# @agentx-cli/script

Build orchestration, native binary bundling, and tool runners for AgentX.

[![License: MIT](https://img.shields.io/badge/License-MIT-000000?style=for-the-badge&logo=opensourceinitiative&labelColor=18181b)](../../LICENSE)

## Overview

Contains automated scripts for:
- Bundling single-file ESM executables using `esbuild`.
- Cross-platform postinstall scripts.
- Packaging distribution bundles and Homebrew formula syncing.
