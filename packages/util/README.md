# @agentx-cli/util

Shared utilities, cross-platform path helpers, formatting, and file diffing for AgentX.

[![License: MIT](https://img.shields.io/badge/License-MIT-000000?style=for-the-badge&logo=opensourceinitiative&labelColor=18181b)](../../LICENSE)

## Utilities Included

- **Path Normalization**: Cross-platform path handling for Windows, macOS, and Linux.
- **Diff Engine**: Unified diff generation and patching.
- **Shell Runner**: Safe command execution with interactive TTY support.
- **Token Counter**: Model-specific token usage and estimation.
