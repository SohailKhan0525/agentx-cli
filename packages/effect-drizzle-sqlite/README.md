## Overview

`@agentx-cli/effect-drizzle-sqlite` integrates [Drizzle ORM](https://orm.drizzle.team) with the [Effect](https://effect.website) ecosystem, providing typesafe database operations, automated migrations, and transactional isolation for AgentX session persistence.
