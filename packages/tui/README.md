# @agentx-cli/tui

> Terminal user interface components, dialogs, command palette, and presentation layer for AgentX built with OpenTUI and SolidJS.

## Features

- **High-Performance Rendering** — Blazingly fast reactive terminal rendering via SolidJS and OpenTUI.
- **Interactive Command Palette** — Quick access to session switching, model selection, variant cycling, and plugin management.
- **Provider Selector** — Intuitive setup and switching across GitHub Copilot, ChatGPT, Google Gemini, Claude, and Local Models.
- **Rich Stream Formatting** — Syntax-highlighted code streaming, status spinners, and real-time build progress feedback.

## Installation

```bash
bun add @agentx-cli/tui
```
