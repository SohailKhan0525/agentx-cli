## Overview

`@agentx-cli/ui` delivers the frontend design system, interactive widgets, animations, theme tokens, and component registry metadata powering AgentX's web and visual companion interfaces.

---

## Features

- **Component Registry**: Curated UI building blocks from ReactBits and 21st.dev.
- **Theme Tokens**: Dark mode, glassmorphism, accent colors, and modern typographic palettes.
- **Micro-Animations**: Smooth transitions, loading spinners, toast notifications, and dialog modals.
- **Accessible & Responsive**: Fully responsive layout primitives tested across desktop and mobile.
