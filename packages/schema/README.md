# @agentx-cli/schema

> Authoritative data schemas, configuration specifications, and TypeScript type definitions for AgentX.

## Overview

- Configuration schemas for `agentx.json` workspace settings.
- Message, prompt, tool call, and stream event models.
- Database, provider, and session serialization contracts.

## Installation

```bash
bun add @agentx-cli/schema
```
