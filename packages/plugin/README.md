# @agentx-cli/plugin

> Extensible plugin architecture and authentication hooks for AgentX.

## Supported Plugins

- **Codex Auth Plugin** — Seamless authentication and token management for ChatGPT/OpenAI models.
- **Copilot Auth Plugin** — OAuth / PAT lifecycle management for GitHub Copilot.

## Installation

```bash
bun add @agentx-cli/plugin
```
